# VAHomeMath Growth Intelligence System

This repository contains the PostgreSQL data foundation for the VAHomeMath Growth
Intelligence System (GIS). Epic 1 establishes multi-tenant ownership, source provenance,
data-rights metadata, and ingestion-run history without changing any customer-facing product.

See [local development](docs/gis/local-development.md) for setup commands and
[the architecture](docs/gis/architecture.md) for design context.
