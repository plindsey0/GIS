# Target portfolio

Epic 26A presents four planning tiers without creating a competing target lifecycle:

- **Discovery**: an existing candidate still gathering planning evidence.
- **Watchlist**: an existing paused, dormant, rejected, or retired target retained for context.
- **Active**: an existing operationally active target; only this tier reflects current authorization.
- **Strategic**: a non-active target with high or critical latest planning priority; review guidance, not authorization.

`CollectionTarget.status`, latest planning decisions, cadence, blockers, overrides, and scheduled targets remain authoritative. Portfolio derivation never activates, pauses, authorizes, schedules, or collects. Operators use existing Collection and provider-control workflows for changes.

Priority is the existing deterministic evidence-value score. Information value is the number of candidate failures a bounded action may help. Cost is shown only when known; unknown remains unknown. Cadence comes only from persisted planning decisions.
